Trim handles set where the program begins and ends inside the track; the element timeline counts from the start handle. Tempo is estimated from the track and drawn as beat ticks on the timeline so elements can be placed on the music.

Drag an element to place it on the ice · 60 × 30 m international rink

The gold line is the skating path built between the elements: lobes and edges, with crossovers on the curves and a backward approach into every toe and edge jump. Judges sit along the bottom long side.

Required elements

Checks follow the 2026/27 ISU requirements (Communication 2770): required jump types, spin positions and change-of-foot rules, step sequence, element count, program length, and the 1.1× factor for the last jumping pass in the second half. Base values use the current ISU Scale of Values at the level entered; levels and GOE are judged live and are not scored here.
